Exercises Library

Learn exercises and what muscles they target

Chest Exercises

Bench Press

Targets: Chest, Triceps, Front Delts

  1. Lie flat on bench
  2. Grip bar slightly wider than shoulders
  3. Lower to chest
  4. Push up explosively

Incline Dumbbell Press

Targets: Upper Chest

  1. Set bench to incline
  2. Hold dumbbells at chest level
  3. Press upward
  4. Control the descent

Chest Fly

Targets: Chest

  1. Lie on bench
  2. Open arms wide
  3. Bring dumbbells together
  4. Squeeze chest

Push Ups

Targets: Chest, Triceps

  1. Hands shoulder-width apart
  2. Keep body straight
  3. Lower chest to ground
  4. Push back up

Cable Crossover

Targets: Inner Chest

  1. Set cables high
  2. Pull hands together
  3. Squeeze chest
  4. Return slowly

Back Exercises

Pull Up

Targets: Lats, Biceps

  1. Grab bar
  2. Hang fully
  3. Pull chest to bar
  4. Lower slowly

Lat Pulldown

Targets:Lats

  1. Sit at a machine
  2. Grip bar wide
  3. Pull to chest
  4. Control return

Barbell Row

Targets: Mid Back

  1. Bend forward
  2. Grip barbell
  3. Pull to stomach
  4. Lower slowly

Seated Cable Row

Targets: Back

  1. Sit straight
  2. Pull handle
  3. Squeeze back
  4. Return controlled

Deadlift

Targets: Full Back, Legs

  1. Feet shoulder width
  2. Grip bar
  3. Lift with straight back
  4. Lower slowly

Biceps Exercises

Barbell Curl

Targets: Biceps

  1. Stand straight
  2. Grip bar
  3. Curl up
  4. Lower slowly

Dumbbell Curl

Targets: Biceps

  1. Hold dumbbells
  2. Curl one arm
  3. Alternate sides
  4. Control movement

Hammer Curl

Targets: Biceps, Forearm

  1. Neutral grip
  2. Curl dumbbells
  3. Keep elbows still
  4. Lower slowly

Preacher Curl

Targets: Biceps

  1. Rest arms on pad
  2. Curl bar
  3. Squeeze top
  4. Lower controlled

Triceps Exercises

Tricep Pushdown

Targets: Triceps

  1. Hold cable bar
  2. Push down
  3. Squeeze triceps
  4. Return slowly

Skull Crusher

Targets: Triceps

  1. Lie on bench
  2. Lower bar to forehead
  3. Extend arms
  4. Control movement

Dips

Targets: Triceps

  1. Hold bars
  2. Lower body
  3. Push up
  4. Repeat

Shoulder Exercises

Overhead Press

Targets: Shoulders

  1. Hold bar at shoulders
  2. Press upward
  3. Lock arms
  4. Lower slowly

Lateral Raise

Targets: Side Delts

  1. Hold dumbbells
  2. Lift sideways
  3. Stop at shoulder height
  4. Lower controlled

Rear Delt Fly

Targets: Rear Shoulders

  1. Bend forward
  2. Raise dumbbells back
  3. Squeeze shoulders
  4. Return slowly
